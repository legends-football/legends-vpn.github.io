نمونهٔ گزارش قابل گسترش پس از اتصال بک‌اند

وضعیت API: تابع Supabase با نام legends-api برای تست تنظیم شده است؛ اتصال واقعی باید در مرورگر آزمایش شود. این فایل عمومی است؛ کلید محرمانه یا رمز را اینجا قرار نده. اتصال واقعی پس از استقرار بک‌اند HTTPS و پیاده‌سازی احراز هویت سمت سرور فعال می‌شود.
کلیدهای API، رمزهای سرور و کانفیگ‌های حساس را داخل HTML عمومی یا مخزن GitHub قرار نده. اطلاعات محرمانه باید فقط در بک‌اند امن نگه‌داری شوند.
